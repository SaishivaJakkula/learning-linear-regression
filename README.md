# 📈 Linear Regression Basics

This repository explains the fundamentals of **Linear Regression**, one of the most important algorithms in Machine Learning used for predicting continuous numerical values.

---

## 📌 Project Overview

Linear Regression is a supervised learning algorithm that models the relationship between an input variable (X) and an output variable (Y) by fitting the best possible straight line through the data points. The goal is to make accurate predictions while minimizing the error between actual and predicted values.

## 🧮 Linear Regression Equation

Linear Regression follows the equation:

Y = mX + c

Where:

- **X** = Input variable  
- **Y** = Predicted output  
- **m** = Slope of the line (rate of change)  
- **c** = Intercept (value of Y when X = 0)

The model tries to find the best values of **m** and **c** so that prediction error is as small as possible.

---

## ⚙️ How the Model Learns

1. The model receives training data (input and output values).  
2. It draws an initial line.  
3. It calculates prediction error.  
4. It adjusts the line to reduce the error.  
5. This process continues until the best fit line is found.

The error is minimized using a method called **Mean Squared Error (MSE)**.
